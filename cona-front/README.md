1. Instala dependencias (si no lo hiciste ya):

```
npm install
```

2. Inicia la app en desarrollo:

```
npm run dev
```

Dependencias usadas en las vistas migradas: `axios`, `sweetalert2`, `lucide-react`, `react-router-dom`, `tailwindcss`.

Si Tailwind no está inicializado en tu entorno, ya agregé `tailwind.config.cjs` y `postcss.config.cjs`, y añadí las directivas en `src/index.css`.
